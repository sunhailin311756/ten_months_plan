# 第 08 个月 · 机器人与机电融合（2027年04月）

> **本月主题**：机械、电子、控制、系统一起转起来
>
> **本月目标**：完成一个机电一体化系统：机械、电子、控制、系统软件协同工作，并具备故障保护与可量化验收。
>
> **每日 2 小时模板**：30min 机械/控制 + 70min 系统项目 + 10min 记录 + 10min 复盘

## 1. 本月知识地图

### 机械
- CAD建模
- 3D打印
- 装配公差
- 机构设计
- 底盘/支架

### 电子
- 传感器选型
- 电机驱动
- 电源
- 自制PCB集成

### 控制
- PID
- 编码器
- IMU
- 差速运动学

### 系统
- 通信协议
- 状态机
- 故障保护
- 供电预算
- 模块化接口

## 2. 四周计划

| 周次 | 主题 | 关键任务 |
| --- | --- | --- |
| 第 1 周 | 系统设计 | 需求/系统框图/供电预算/接口表；输出选型清单 |
| 第 2 周 | 机械与装配 | CAD建模底盘/支架；3D打印或手板；装配与公差检查 |
| 第 3 周 | 电子与控制 | 集成第6月控制板；电机+编码器+IMU；差速运动学 |
| 第 4 周 | 系统联调 | 状态机+遥控/自动模式；故障保护；实测数据；演示视频 |

## 4. 月末交付物

- [ ] 系统框图+接口表+供电预算

## 5. 验收标准

- [ ] 完成机械+电子+固件的系统集成
- [ ] 小车走直线/转向（或机械臂完成基础动作）
- [ ] 有故障保护（限位/过流/急停）
- [ ] 能讲解各模块接口与数据流

## 6. 避坑指南

1. 先做机械再想电子：先画系统框图
2. 只跑通不开环调试：逐模块验证
3. 电池直接怼MCU：明确电源树与稳压
4. 不设验收指标：用可量化指标验收

## 7. 资源与工具

- Fusion 360 / FreeCAD
- 3D打印机或打印服务
- 直流电机+编码器、IMU（MPU6050）
- 小车底盘/机械臂套件
- 第6月自研控制板
