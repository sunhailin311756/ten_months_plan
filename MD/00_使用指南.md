## 3. 每天 2 小时怎么用

1. **30min 理论/复习**：读当天主题对应的教材、手册或错题本，把新概念写进笔记。
2. **80min 实操**：优先动手，写代码、搭电路、调板子；遇到问题先复现，再查原因。
3. **10min 日志/复盘**：记录完成项、卡点、明天动作，并更新 Git 或笔记。

## 4. 每周节奏

| 时间 | 做什么 |
| --- | --- |
| 周一 | 启动本周主题，准备资料和工具 |
| 周二至周四 | 按当月文件执行 3 个核心任务 |
| 周五 | 综合串联，把本周内容做成 1 个可运行 Demo/实验 |
| 周六 | 周复盘：重做最难任务、整理笔记、提交 Git |
| 周日 | 补漏/休息：完成遗留任务或做拓展题 |

## 5. 每月闭环

> 目标 -> 四周拆解 -> 每日实操 -> 周末复盘 -> 月末验收 -> 下月衔接

每个月按「目标 -> 四周拆解 -> 每日实操 -> 周末复盘 -> 月末验收 -> 下月衔接」推进，
月末把交付物和验收标准逐项打勾，再进入下一个月。

## 6. 学习原则

1. 输出导向：每个知识点配一个可运行Demo
2. 动手优先：每天实操时间不低于70分钟
3. 少而深：一次只攻一个外设/协议
4. 记录Bug：问题-原因-解决三步归档
5. 周复盘+月验收：用数据检查进度

## 8. 全局里程碑

- 第3月末：能独立建STM32工程并完成按键+LED+中断
- 第6月末：完成第一块自研STM32控制板并打样焊接
- 第8月末：跑通机器人/机电系统完整闭环
- 第10月末：形成作品集、简历与面试题库并开始投递

## 9. 使用方法

1. 每月 1 号打开对应月份文件，先读「本月目标」和「四周计划」。
2. 每天开始前看当天那一行，按 30+80+10 执行，完成后打勾或标记。
3. 周六必须写周复盘；周日用于补漏，不要欠账太多。
4. 月末完成「月末交付物」和「验收标准」，全部勾选后再进入下一个月。
5. 遇到瓶颈先降低单点难度，不要跳过实操；笔记和 Git 是唯一的进度证据。
