## 2. C 语言完整知识点

### 2.1 `.c` 文件开头模板（标准模板）

```c
/*
 * 文件名：hello.c
 * 作者：你的名字
 * 日期：2026-09-01
 * 功能：程序功能的一句话说明
 * 修改记录：
 *   v1.0 2026-09-01 初始版本
 */

#include <stdio.h>      // 标准输入输出头文件，printf/scanf 都靠它

#define PI 3.14159      // 宏常量，全大写命名

// 主函数：C 程序入口，程序从这里开始执行
int main(void)
{
    // 1. 定义变量并初始化
    int age = 20;
    double score = 95.5;

    // 2. 业务逻辑
    score = score + 2.5;

    // 3. 输出结果
    printf("age = %d\n", age);
    printf("score = %.1f\n", score);

    return 0;           // 返回 0 表示程序正常结束
}
```

模板各部分说明：

| 部分 | 作用 |
| --- | --- |
| 文件头注释 | 记录文件名、作者、日期、功能、修改记录，方便回看 |
| `#include <stdio.h>` | 引入标准输入输出库 |
| `#define` | 定义宏常量，程序里所有 `PI` 都会被替换成 `3.14159` |
| `int main(void)` | 主函数，`void` 表示不接收命令行参数 |
| `return 0;` | 返回 0 表示程序成功结束 |
| 代码注释 | `//` 单行注释、`/* */` 多行注释 |

多文件项目常用配套头文件模板：

```c
// 文件名：utils.h
#ifndef UTILS_H
#define UTILS_H

int add(int a, int b);
int multiply(int a, int b);

#endif
```

```c
// 文件名：utils.c
#include "utils.h"

int add(int a, int b)
{
    return a + b;
}

int multiply(int a, int b)
{
    return a * b;
}
```

编译运行命令：

```text
gcc hello.c -o hello.exe
./hello.exe
```

### 2.2 变量类型与位数（完整表）

> 位数和大小与编译平台有关，下面以常见 PC 平台（32 位/64 位 GCC）为准；可以用 `sizeof(类型)` 实测，用 `<limits.h>`、`<float.h>` 查具体范围。

| 类型 | 位数 | 字节 | 取值范围 | printf 格式符 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `char` | 8 位 | 1 字节 | -128 ~ 127 | `%c`、`%hhd` | 字符型，也能存小整数 |
| `unsigned char` | 8 位 | 1 字节 | 0 ~ 255 | `%c`、`%hhu` | 无符号字符 |
| `short` | 16 位 | 2 字节 | -32768 ~ 32767 | `%hd` | 短整型 |
| `unsigned short` | 16 位 | 2 字节 | 0 ~ 65535 | `%hu` | 无符号短整型 |
| `int` | 32 位 | 4 字节 | -2147483648 ~ 2147483647 | `%d` | 最常用整型 |
| `unsigned int` | 32 位 | 4 字节 | 0 ~ 4294967295 | `%u` | 无符号整型 |
| `long` | Windows 32 位 / Linux 64 位 | 4/8 字节 | 平台相关 | `%ld` | 长整型 |
| `long long` | 64 位 | 8 字节 | -9223372036854775808 ~ 9223372036854775807 | `%lld` | 大整数 |
| `float` | 32 位 | 4 字节 | 约 ±3.4e38，有效数字 6-7 位 | `%f` | 单精度浮点 |
| `double` | 64 位 | 8 字节 | 约 ±1.8e308，有效数字 15-16 位 | `%f`、`%lf` | 双精度浮点，默认浮点类型 |
| `_Bool` | 8 位 | 1 字节 | 0 或 1 | `%d` | 布尔类型，非 0 即真 |
| `size_t` | 32/64 位 | 4/8 字节 | 无符号 | `%zu` | `sizeof` 的返回类型 |

重点记忆：

```c
#include <stdio.h>

int main(void)
{
    printf("int    = %zu 字节\n", sizeof(int));
    printf("char   = %zu 字节\n", sizeof(char));
    printf("double = %zu 字节\n", sizeof(double));
    return 0;
}
```

### 2.3 变量定义、初始化与赋值

语法：

```c
类型 变量名 = 初始值;
类型 变量名1, 变量名2, 变量名3;
```

示例：

```c
int age = 20;              // 定义并初始化
double price;              // 先定义
price = 9.9;               // 再赋值
int a = 1, b = 2, c = 3;   // 一次定义多个
```

规则：

- 变量必须先声明再使用。
- 未初始化的局部变量值是"垃圾值"，不要直接使用。
- 变量名在同一个作用域内不能重复。
- 类型不同可以互相赋值，但会发生隐式转换，可能丢精度。
- 强制转换：`(double)a / b`，把 `a` 先转成 `double` 再做除法。

```c
int a = 7, b = 2;
double r1 = (double)a / b;   // 3.5，正确
double r2 = a / b;           // 3.0，先整数除法再转 double，结果不对
```

### 2.4 命名规则

硬性规则：

- 标识符只能由字母、数字、下划线 `_` 组成。
- 不能以数字开头。
- 不能与 C 关键字重复：`int`、`float`、`return`、`if`、`else`、`for`、`while`、`switch`、`case`、`break`、`continue`、`struct`、`enum` 等。
- 区分大小写：`age` 和 `Age` 是两个不同的变量。
- 名称长度没有硬限制，但要可读。

推荐风格：

| 场景 | 推荐写法 | 示例 |
| --- | --- | --- |
| 普通变量 | 小驼峰或下划线 | `myAge`、`my_age` |
| 常量 | 全大写加下划线 | `MAX_SIZE`、`LED_PIN` |
| 函数 | 动词开头 | `getScore()`、`printInfo()` |
| 循环变量 | 允许 `i`、`j`、`k` | `for (int i = 0; i < 10; i++)` |

好例子 vs 坏例子：

```c
int studentScore = 90;    // 好：语义清楚
int ss = 90;              // 差：看不出是什么
int 2score;               // 错：不能数字开头
int score-1;              // 错：不能有减号
int return;               // 错：关键字
```

### 2.5 常量与宏

| 类型 | 写法 | 示例 |
| --- | --- | --- |
| 字面常量 | 直接写值 | `42`、`3.14`、`'A'`、`"hello"` |
| `const` 常量 | 声明时加 `const` | `const double TAX = 0.06;` |
| 宏常量 | `#define 名字 值` | `#define MAX_SIZE 100` |

```c
#include <stdio.h>

#define LED_PIN 13

int main(void)
{
    const int MAX_TRY = 5;
    printf("LED_PIN = %d\n", LED_PIN);
    printf("MAX_TRY = %d\n", MAX_TRY);
    return 0;
}
```

### 2.6 运算符与常用表达式

运算符分类：

| 类别 | 运算符 | 示例 |
| --- | --- | --- |
| 算术 | `+ - * / %` | `sum = a + b;` |
| 赋值 | `= += -= *= /= %=` | `total += price;` |
| 自增自减 | `++ --` | `i++;` |
| 关系 | `> < >= <= == !=` | `a > b` |
| 逻辑 | `&& \|\| !` | `a > 0 && a < 100` |
| 三目 | `? :` | `max = a > b ? a : b;` |
| 取大小 | `sizeof` | `sizeof(int)` |
| 位运算 | `& \| ^ ~ << >>` | 后面学寄存器时会用 |

`++i` 与 `i++` 的区别：

```c
int n = 5;
int x = ++n;   // n 先自增成 6，再赋值，x = 6
int y = n++;   // 先赋值 y = 6，n 再自增成 7
```

整数除法与浮点除法：

```c
int a = 7, b = 2;
printf("%d\n", a / b);          // 3，整数除法直接舍去小数
printf("%f\n", (double)a / b);  // 3.500000，先转 double
printf("%d\n", a % b);          // 1，取余
```

常用表达式集合：

```c
int a = 10, b = 3;
int sum = a + b;                 // 13
int diff = a - b;                // 7
int prod = a * b;                // 30
int quot = a / b;                // 3
int rem = a % b;                 // 1

int total = 0;
total += a;                      // total = 10
total *= 2;                      // total = 20

int max = (a > b) ? a : b;       // 10
int isEven = (a % 2 == 0);       // 1
char next = 'A' + 1;             // 'B'
```

优先级速记：括号 > 单目（`++ -- ! sizeof`） > 乘除取余 > 加减 > 关系 > 逻辑与 > 逻辑或 > 三目 > 赋值。

```c
int r = 2 + 3 * 4;     // 14，不是 20
int r2 = (2 + 3) * 4;  // 20，用括号控制
```

### 2.7 输入输出

`printf` 常用格式符：

| 格式符 | 含义 |
| --- | --- |
| `%d` | 十进制整数 |
| `%u` | 无符号十进制整数 |
| `%f` | 浮点数 |
| `%.2f` | 浮点数，保留 2 位小数 |
| `%lf` | double（scanf 中使用） |
| `%c` | 单个字符 |
| `%s` | 字符串 |
| `%p` | 地址（指针） |
| `%zu` | size_t 无符号整数 |
| `%%` | 输出一个百分号 |

转义字符：

| 转义 | 含义 |
| --- | --- |
| `\n` | 换行 |
| `\t` | 水平制表（Tab） |
| `\\` | 反斜杠 |
| `\"` | 双引号 |
| `\0` | 字符串结束符 |

`scanf` 正确写法：

```c
int age;
double score;
char name[50];

scanf("%d", &age);        // 普通变量要加 &
scanf("%lf", &score);     // double 用 %lf
scanf("%s", name);        // 字符数组/字符串不加 &
```

常见坑：

- 忘写 `&`：`scanf("%d", age);` 会崩溃或乱存。
- 输入回车残留：读字符前用 `getchar();` 清掉回车。
- 整数输入后读字符会被回车吃掉。

```c
int n;
char op;
scanf("%d", &n);
getchar();                // 清掉回车
scanf("%c", &op);
```

### 2.9 常见错误与调试

| 错误类型 | 例子 | 排查方法 |
| --- | --- | --- |
| 编译错误 | 少分号、括号不配对 | 看编译器报错行号，先修第一个错误 |
| 未定义变量 | `printf("%d", age);` 但没定义 | 检查拼写和声明位置 |
| scanf 忘 `&` | `scanf("%d", age);` | 改成 `&age` |
| 整数除法丢小数 | `a / b` 结果变整数 | 先转 `(double)` |
| 中文标点 | 用 `；` 代替 `;` | 代码里只能使用英文标点 |
| 数组越界 | 访问 `a[10]`，数组只有 10 个元素 | 下标从 0 到 `n-1` |

调试三板斧：

1. 看编译警告：编译加 `-Wall`。
2. 用 `printf` 打印中间变量。
3. 二分定位：注释掉一半代码，找出问题范围。

```text
gcc hello.c -o hello.exe -Wall
```

## 3. 电路基础完整知识点

### 3.1 基本物理量

| 物理量 | 符号 | 单位 | 常用换算 |
| --- | --- | --- | --- |
| 电压 | U | 伏特 V | 1V = 1000mV |
| 电流 | I | 安培 A | 1A = 1000mA |
| 电阻 | R | 欧姆 Ω | 1kΩ = 1000Ω，1MΩ = 1000kΩ |

### 3.2 欧姆定律与功率

```text
U = I × R
I = U / R
R = U / I
```

```text
P = U × I
P = I² × R
P = U² / R
```

示例：5V 电压、10mA 电流，电阻是多少？

```text
R = 5 / 0.01 = 500 Ω
```

### 3.3 串并联与分压分流

串联：

```text
R总 = R1 + R2 + ...
电流相同，电压按电阻比例分压
```

并联：

```text
1/R总 = 1/R1 + 1/R2 + ...
电压相同，电流按电阻反比分流
```

分压公式（两个电阻串联）：

```text
V1 = V总 × R1 / (R1 + R2)
```

示例：5V 接 1kΩ + 1kΩ，每个电阻分到 2.5V。

### 3.4 LED 限流电阻计算

已知：电源 5V，LED 压降约 2V，工作电流 10mA。

```text
R = (5 - 2) / 0.01 = 300 Ω
```

电阻功率：

```text
P = I² × R = 0.01² × 300 = 0.03W
```

结论：选 **330Ω、1/4W** 常用电阻即可。

### 3.5 万用表使用

| 测量 | 接法 | 注意 |
| --- | --- | --- |
| 电压 | 红黑表笔并联在元件两端 | 选直流电压档，量程先大后小 |
| 电流 | 串联进回路 | 注意最大量程，不要直接并联电源 |
| 电阻 | 并联在电阻两端 | 必须先断电，不能带电测 |
| 通断 | 蜂鸣档 | 响表示导通 |

### 3.6 面包板

- 上下两排是电源轨，通常标 `+` 和 `-`。
- 中间横向 5 个孔内部相连。
- 中间竖向被凹槽隔开，两边不互通。
- 改线前先断电，防止短路烧元件。
