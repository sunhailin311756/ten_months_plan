## 1. 作业要求

写一个 C 程序，完成三件事：

1. 学习登记：读取姓名和本周计划学习 C 的天数并输出。
2. 元件采购单：读取元件数量和单价，计算商品小计、商品合计、税费、运费和应付总额。
3. LED 限流电阻计算：读取电源电压、LED 正向压降和目标电流，计算需要的限流电阻与电阻功率。

约束：

- 只使用本周知识，不写 `if`、`for`、`while`。
- 程序开头必须有文件头注释，包含文件名、作者、日期、功能和修改记录。
- 必须至少用到 `int`、`double`、字符数组这三种数据类型。
- 必须用 `#define` 定义税费常量，命名为 `TAX_RATE`，值为 `0.06`。
- `printf` 中浮点数保留两位小数；`scanf` 读 `double` 时使用 `%lf`。
- 不要依赖教材示例代码，先自己想清楚再写。

## 2. 主程序细节

### 2.1 第一部分：学习登记

先输出一行程序标题，再读取：

```text
请输入姓名：sun
请输入本周计划学习 C 的天数(整数)：5
```

然后输出：

```text
sun 的学习登记
本周计划学习 C：5 天
```

`name` 使用 `char` 数组存储，`days` 使用 `int` 存储。

### 2.2 第二部分：元件采购单

依次读取以下数据：

```text
请输入电阻数量(整数)：50
请输入电阻单价(元)：0.35
请输入 LED 数量(整数)：20
请输入 LED 单价(元)：0.18
请输入运费(元)：5
```

计算规则：

```text
电阻小计 = 电阻数量 * 电阻单价
LED 小计 = LED 数量 * LED 单价
商品合计 = 电阻小计 + LED 小计
税费 = 商品合计 * TAX_RATE
应付总额 = 商品合计 + 税费 + 运费
```

参考输出格式：

```text
元件     数量     单价(元)    小计(元)
------------------------------------
电阻     50       0.35        17.50
LED      20       0.18        3.60
------------------------------------
商品合计                      21.10
税费(6%)                       1.27
运费                           5.00
应付总额                      27.37
```

数字必须来自变量，不能写死。

### 2.3 第三部分：LED 限流电阻计算

依次读取：

```text
请输入电源电压 U(V)：5
请输入 LED 正向压降(V)：2
请输入目标电流(mA)：10
```

要求：

- 电流以整数毫安读入，例如 `int currentMa = 10;`。
- 换算成安培时必须除以 `1000.0`，这一行旁边用注释说明为什么不能只写 `1000`。
- 使用以下公式计算：

```text
currentA = currentMa / 1000.0
resistorOhm = (supplyVoltage - ledForwardVoltage) / currentA
resistorPower = currentA * currentA * resistorOhm
```

参考输出：

```text
限流电阻：300.00 Ω
电阻消耗功率：0.03 W
```
